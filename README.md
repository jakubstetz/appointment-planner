# 📅 Appointment Planner

A simple React-based contact and appointment management app. This project was built early in my software journey as part of Codecademy’s Full-Stack Engineer curriculum.

This project serves as a snapshot of my early work with React — particularly with state management, form handling, and component design.

## 🛠️ Features

- Add, view, and delete contacts
- Schedule and track appointments
- Form validation and duplicate prevention
- Modular design with functional components and hooks

## 🧠 Key Concepts Practiced

- React state and props
- Functional components
- Controlled form elements
- Component composition and reuse

## ⚙️ Tech Stack

- React (functional components & hooks)
- Basic CSS
